# HydroSeal Learning Center Audit

Date: 2026-07-30
Repository: `GsCommand/hydrosealpavers-site`

## Decision

The current Learning Center advertises 53 guides. The final editorial library will contain no more than 20 substantive articles plus the Learning Center index. All surviving pages will use one simple, image-free blog-post template.

Classification labels:

- **KEEP** — preserve the existing URL and rebuild as an authoritative article.
- **MERGE** — incorporate useful material into a KEEP article, then permanently redirect.
- **RETIRE** — remove from navigation and sitemap; permanently redirect to the closest relevant article or category where appropriate.
- **CATEGORY** — category/index page, not counted as an article.

## Indexing findings

The domain is crawlable, but the Learning Center has weak independent search visibility. The current sitemap does not include the Learning Center article set, and many article pages use the same generic placeholder-derived introduction and body. Existing URLs should therefore be preserved only where the topic has strong search intent or the page contains useful original material.

## Image removal rule

For the next implementation pass:

1. Remove all `<img>`, `<picture>`, `<figure>`, `<source>`, image cards, decorative backgrounds, hero images, thumbnails, and image captions from every file under `learning-center/`.
2. Remove Learning Center `og:image`, `twitter:image`, image schema, hero-image CSS variables, and image preload references.
3. Do not remove the global HydroSeal logo from shared site headers or footers outside the Learning Center. For Learning Center pages, use the shared global include so article files themselves remain text-first.
4. Remove image-dependent CSS from the Learning Center stylesheet.
5. Do not delete image assets globally because other service pages may use them.

## Standard article template

Every retained article will use the same simple blog-post structure:

1. Breadcrumbs
2. Category label
3. H1
4. Direct answer summary of roughly 50–90 words
5. Published and updated dates
6. Author/reviewer line
7. Plain article body in one centered column
8. Descriptive H2 sections
9. Lists and comparison tables only when useful
10. A visible FAQ section where the questions genuinely add value
11. Three manually selected related articles as text links
12. One restrained text CTA at the bottom

No hero image, cards, sidebar, carousel, decorative container stack, search widget, or image grid.

## Technical requirements for the rebuild

- Keep static, server-rendered HTML.
- Use one canonical URL per article.
- Use a connected JSON-LD `@graph` containing `WebPage`, `Article`, `BreadcrumbList`, publisher, and author/reviewer where supportable.
- Add real `datePublished` and `dateModified` values.
- Do not output FAQ schema unless the exact FAQ is visible.
- Add only the 20 articles and `/learning-center` to the XML sitemap.
- Add permanent redirects for merged URLs.
- Remove all retired URLs from internal links and sitemap.
- Replace the current builder behavior that disguises placeholder content. The build must fail when placeholder phrases or insufficient article bodies are detected.

## Current conclusion

The Learning Center should be reduced from 53 guides to 20 authoritative pages. Existing search equity is limited, so preserving every weak URL would create more risk than value. The strongest exact URLs are retained above; overlapping URLs will transfer their useful content and redirect rather than disappear without a destination.
